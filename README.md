# Zenith Educate

Responsive website recreation inspired by the public-facing content of [zenitheducate.in](https://zenitheducate.in/).

## Run
Open `index.html` in a browser, or deploy the repository as a static site using GitHub Pages, Netlify, Vercel, or Azure Static Web Apps.

## Included
- Responsive landing page and navigation
- About, programme catalogue, institute highlights and contact sections
- Filterable programme cards
- WhatsApp contact link and email-based enquiry form

## Before production
- Confirm all course names, contact details and claims with the institute.
- Replace demo photography with licensed/approved images.
- Connect the enquiry form to an authorized backend or form provider if direct email is not sufficient.
- Add privacy policy, analytics and hosting configuration as appropriate.

This project recreates public-facing presentation only; it does not include the original site's private assets, backend, database or admin functionality.
